# RavGB requests

**Ask for a new free tool, suggest an improvement, or tell us something is broken.**

RavGB builds small, free command-line tools that each check one thing well: a website, a domain's DNS and email setup, HTTPS certificates, a slow network, a full disk. This is where you tell us what to build next.

## Open a request

[**Open a request**](https://github.com/RavGB/requests/issues/new/choose) and choose one of these:

- **Request a new tool**: a check you wish existed.
- **Suggest an improvement**: an idea for a tool we already have.
- **Report a problem**: a tool gave a wrong result, crashed, or did not run.

You need a free GitHub account. Everything you write here is public, so please leave out passwords, keys and private details.

If the problem is about one tool, you can also open it in that tool's own repository. Both are fine.

## What happens next

1. We read every request and reply, usually within a few business days.
2. Requests we plan to build move to **Planned** on the [RavGB requests board](https://github.com/orgs/RavGB/projects/1), then **In progress**, then **Done**.
3. If we will not build something, we say why and mark it **Not planned**.

## Not a tool request?

- Want RavGB to check your website for you? Ask for the [free website check](https://ravgb.com/free-website-check/).
- Small SaaS team on AWS? Book the [free AWS Cost and Reliability Audit](https://ravgb.com/managed-devops/).
- Found a security problem? Please report it privately. See the [security policy](https://github.com/RavGB/.github/blob/main/SECURITY.md).
- Anything else: [ravgb.com/contact](https://ravgb.com/contact/) or hello@ravgb.com.
